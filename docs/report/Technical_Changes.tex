This audit continues the dev branch from commit 5332011. Origin is Parth{-}73/od and the fork remote is Parth{-}73/OsdagBridge. Existing reporting, CAD capture, quantity calculations and tests were retained. Report\_Before.pdf remains byte{-}identical to the version committed before this audit.%

\section*{1. Load combinations and numerical independence}%
\label{sec:1.Loadcombinationsandnumericalindependence}%
Root cause: LoadCase.add\_load stored each load group's factor, and the combination builder populated it, but OSPGrillage.\_distribute\_load\_types\_to\_model ignored it. Differently labelled combinations with the same available load objects therefore generated identical solver loads.%


%
The distributor now scales the nodal force and moment commands produced by each group exactly once. This covers point, line, patch, nodal and compound loads through a common command path. Factors must be finite. Stored source loads are not mutated. Combination{-}copy helpers also preserve an existing source group's coefficient when applying a new coefficient.%


%
A regression creates a real three{-}dimensional elastic cantilever in OpenSees and verifies that coefficients 1.0 and 1.35 produce displacement responses in the ratio 1.35. Other tests verify nested coefficients, negative compound factors and independent xarray extraction for two distinct named cases.%


%
The regenerated BASIC\_1 moment is {-}2506.442 kNm, BASIC\_2 is {-}2156.616 kNm and BASIC\_3 is {-}2201.762 kNm. SEISMIC\_1 and SEISMIC\_2 are 1321.977 and 1385.102 kNm respectively. Values were obtained from the solver dataset and retain their signed convention.%


%
ACCIDENTAL\_1 through ACCIDENTAL\_3 still have the same applied expression, 1.0DL + 1.0DW + 0.75LL, and the same moment {-}1552.318 kNm. Collision, barge and floating{-}body actions are unavailable in this run. Chapter 4 documents this reason. Chapter 3 now identifies its generic IRC 6 definitions as a catalogue, distinct from the actual applied expressions printed in Chapter 4.%

\section*{2. Traceable deflection calculations}%
\label{sec:2.Traceabledeflectioncalculations}%
The existing procedure uses r = max(Icomp / Isteel, 1) and adjusted displacement = raw displacement / r. The source computes transformed short{-}term composite properties with effective width min(L/4, girder spacing), the concrete modular{-}ratio helper with Kc = 0.5, the deck thickness, haunch and steel section geometry.%


%
In this case Isteel = 8770693002.666668 mm4 and Icomp = 22207031145.0 mm4, giving r = 2.5319585508520372. Those exact properties and ratio are now persisted in every per{-}load{-}case design result and printed for the governing deflection checks.%


%
The governing adjusted live check is G2 under Case2 1xClass70R. Its raw nodal magnitude is 35.360 mm and its adjusted value is approximately 13.966 mm, displayed by the recorded design check as 13.970 mm. The limit is 31.250 mm, giving recorded UR 0.447 and PASS.%


%
The governing total check is G2 under 1.0 DL + 1.0 LL. Its raw value is 62.158 mm, adjusted to approximately 24.549 mm and displayed as 24.550 mm against 41.670 mm, UR 0.589 and PASS. Design{-}check values are rounded to two decimal places by the existing designer.%


%
The diagram is the separately selected 1.0 LL case, whose physical{-}girder maximum is 32.146 mm. The backend selects this static vehicle case by bending moment; it is not the vehicle{-}position envelope governing adjusted deflection. Dynamic allowance has already been applied by the live{-}load generator. The report now identifies the case difference instead of comparing unrelated values.%


%
The composite adjustment remains an existing engineering modelling assumption. This audit verifies its arithmetic and data provenance and does not introduce a new stiffness methodology. Fatigue and stiffener failures remain visible.%

\section*{3. Stiffeners and authoritative summary mapping}%
\label{sec:3.Stiffenersandauthoritativesummarymapping}%
The 2030 mm spacing is the selected panel spacing, recorded as is\_c\_mm. The former optimized report mapping instead read stiff\_int\_space\_req, which is an optional calculated requirement and can be unavailable. The report now maps and labels the selected spacing explicitly, while persisting the optional requirement separately. Existing leg{-}height and other stiffener checks are unchanged.%


%
The detailed transverse{-}shear check reads the bridge composite{-}interface quantities, while the overall table searched for a girder check identifier that had been moved to deck design. Both now use transverse\_shear\_check, a single reader of the same actual demand and capacity.%


%
After the factor correction the transverse{-}shear demand is about 253.33 kN/m against 999.28 kN/m, giving UR 0.25 and PASS. The old 0.18 belongs to the previous unfactored combination results and is not retained artificially.%


%
Moment and shear member rows now use each girder's own recorded checks. Shear yielding and shear buckling share identifier 2, so the largest utilization must govern. A dedicated regression prevents the passing yielding check from hiding the failing buckling check. The overall summary and detailed tables now retain the governing shear failure around UR 1.10.%

%
\section*{4. Engineering references and force terminology}%
\label{sec:4.Engineeringreferencesandforceterminology}%
The imported composite helper is IRC22\_2014 in irc22\_2015.py. Both its module docstring and clause documentation explicitly identify IRC 22:2014. Report citations now identify that implemented basis and explain the filename discrepancy. This change does not migrate any engineering formula.%


%
Deck design imports IRC112\_2019 from irc112\_2019.py, whose module, class and effective{-}width equation documentation explicitly identify IRC 112:2020. The remaining IRC 112:2011 narrative was corrected using this source evidence. Older filenames alone were not treated as an edition declaration.%


%
Chapter 4 headings now describe end vertical forces and start/finish sums. They do not label them as nodal support reactions. The dataset stores member forces but no direct nodal reaction array.%


%
Global x increases along the span, y is vertical and z transverse. Report locations are global x in metres. Summed end forces use the first element's Vi and minus the last element's Vj, divided by 1000 to obtain kN. These local member{-}end signs do not establish an upward{-}positive nodal{-}reaction convention.%
