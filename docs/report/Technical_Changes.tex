\section*{Confirmed root causes and corrections}%
\label{sec:Confirmedrootcausesandcorrections}%
The original analysis{-}result extractor paired global minimum{-}x and maximum{-}x nodes. On the 14{-}degree skewed mesh, these selected extreme corners and produced one crossing path. An edge{-}aware cache could then exclude that path, leaving Chapter 4 empty. analysis\_results.py now follows connected constant{-}z longitudinal mesh lines, orders elements along x and labels the two edge beams separately. Both report and design entry points now pass the actual edge distance. Three physical girders are assessed, with two edge mesh lines excluded.%


%
The section take{-}off read stale input area 0.02388012 m² and input mass, while the design module used final plate geometry. The final area is independently computed as (1390 {-} 18 {-} 18) times 8 plus two times 420 times 18, giving 25952 mm². Three 25 m girders therefore contain 1.94640 m³ of plate steel and weigh 15.2792 MT at 7850 kg/m³. The take{-}off now derives all three values from final geometry. Stiffeners and connection material are excluded from this plate{-}only model.%


%
Cross{-}bracing quantities previously assumed one representative area and a guessed panel count. The backend now records the number of interior transverse stations in the generated mesh. The take{-}off sums pair{-}specific final areas and member lengths at those stations. Chord enablement is respected. End diaphragms use their own final mass{-}per{-}metre properties and recorded lengths at both supports.%


%
Crash{-}barrier defaults stored mm² while GUI calculations stored m² under the same key. Defaults and GUI now record m² explicitly. Legacy files are resolved only when one unit interpretation agrees with the saved line load and density. Ambiguous cases remain Not calculated. The audited RCC barrier total is about 15.12 m³ using the saved rounded area.%


%
The previous reinforcement quantity was a 120 kg/m³ allowance unrelated to the designed bars. It is now Not calculated because layer extents, laps and anchorage are unavailable. The chart marks its mass unavailable. Stud quantity uses the adopted spacing, rounds interval count upward, and identifies the quantity as cylindrical shank steel.%


%
Per{-}load{-}case design checks serialize their identifier as id, while top{-}level checks use check\_id. The governing{-}check reader now accepts both schemas. This fixes previously empty serviceability rows and retains the recorded load case and girder.%


%
The needspace hook before longtables caused continuation headings to appear before new captions near page boundaries. The hook was removed and empty endfoot/endlastfoot definitions added to the shared header macro. Two actual compiled layout regressions confirm one caption and one heading per occupied page.%

\section*{Deflection investigation}%
\label{sec:Deflectioninvestigation}%
The 1.0 LL analysis case is selected by the backend from a governing static vehicle case using bending moment. Its raw plotted displacement is about 32.146 mm and includes the dynamic allowance already applied by the load generator. It is a single selected case rather than the complete envelope of all vehicle positions.%


%
The existing designer applies a composite{-}to{-}steel stiffness correction to raw grillage deflections and evaluates individual live cases and the DL + LL case. The audited governing recorded live check is 13.970 mm against 31.250 mm, UR 0.447. The recorded total check is 24.550 mm against 41.670 mm, UR 0.589. The report now exposes the correction basis and the raw maxima separately and uses the same recorded checks in Chapters 4, 5 and the overall summary.%


%
No structural deflection formula was changed in this audit. The legacy composite correction is an applied modelling assumption requiring engineering acceptance. A direct comparison between a raw diagram ordinate and an adjusted design{-}check limit does not establish the status of the adjusted check.%

\section*{Numerical reporting and remaining conditions}%
\label{sec:Numericalreportingandremainingconditions}%
Chapter 4 now contains 45 available load{-}case/combination summaries with signed moment and shear demands, physical girder labels and available x locations. End vertical force sums are derived from longitudinal member end forces. They are explicitly labelled with that basis because direct nodal support reactions are absent from the stored dataset. Failed extraction is retained as unavailable instead of silently accumulating a zero.%


%
Chapter 2 identifies initial transverse{-}member sections, while Chapter 5 and the quantity model use final designed sections. Duplicate identifier ranges such as B1M1 to B1M1 are collapsed to the stored identifier. The executive summary lists all six final girder section dimensions including web thickness and reports the governing check separately for each girder.%


%
Missing inputs are labelled Not provided. Missing quantities are Not calculated. Missing required checks are Not assessed and can produce an Incomplete summary. Valid zeros remain numeric. A valid failed check determines overall failure. The temperature table formats each available temperature with its unit and prints missing values without malformed signs or empty units.%


%
The minimum shade temperature remains missing in the reconstructed case, so thermal loading is unavailable. Chapter 4 explicitly records that generated combination expressions do not prove a missing thermal action was analysed. This input condition requires resolution before using the case as a complete engineering design.%


%
The existing modules identify IRC 22:2015 and IRC 112:2020 in report references. The composite implementation imports the legacy class IRC22\_2014 from irc22\_2015.py. This naming discrepancy is documented, with no formula migration. Applied material unit weights are reported from the saved inputs alongside the explicit quantity{-}density basis, rather than implying they equal generic assumptions.%


%
The audited report retains the approximately 2.16 girder fatigue failure and intermediate{-}stiffener leg{-}height failure. Correct physical{-}girder extraction also exposes any additional failing checks reported by the designer. Successful PDF generation is a reporting validation result.%
